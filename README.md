# calculate-calories
1. What does the project do?
 It calculates the daily calorie intake and keeps track of meals. The project helps users control their diet based on individual parameters and a list of foods. This project is text-based and not widget-based. It works exclusively in the terminal.
2. Functions:
- entering personal data (gender, age, height, weight, and activity);
- calculating the daily calorie intake;
- selecting foods from a predefined list with their calorie content;
- adding meals (breakfast, lunch, dinner, and snacks);
- display the current calorie consumption and the remaining amount
3. How to get started?
 Copy the code from the file and paste it into the code editor, create a new terminal, and run the code.

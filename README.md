# calculate-calories
1. Что делает проект?
  Расчитывает суточную норму калорий и ведёт учёт приёмов пищи. Проект поможет пользователям контролировать рацион на основе индивидуальных параметров и списка продуктов. Этот проект текстовый, не виджетовый. Работает исключительно в терминале
2. Функции:
- ввод персональных данных (пол, возраст, рост, вес, активность);
- расчёт суточной нормы калорий;
- выбор продуктов из предопределённого списка с указанием калорийности;
- добавление приёмов пищи (завтрак, обед, ужин, перекус);
- отображение текущего потребления калорий и остатка до нормы
3. Как начать работу?
  Скачать файл и запустить в терминале.
